## Observable wire behavior

- REST: GET `/api/v1/telemetry/estates/{estateId}/blocks/{blockId}/latest`, at most one reading per kind sorted by kind. Explicit coverage NONE/PARTIAL/COMPLETE means kind presence only; no staleness, calibration, physical accuracy or agronomic safety assertion. Missing readings are absent, never zero-filled. Unknown/inactive block returns 404; authorized active block with no readings returns empty 200; dependency unavailable returns 503. Problem responses also specify 400/401/403/429. Gateway and service independently validate signed issuer/audience and trusted role/estate scope before queries. Reuse existing Estate read roles: PLATFORM_ADMIN/PLANTATION_ADMIN select explicit target; ESTATE_ADMIN/ESTATE_MANAGER/VIEWER/FIELD_SUPERVISOR/FIELD_WORKER/AUDITOR require trusted estate_ids. No new product role or permission for MQTT derived from REST roles.
- MQTT input: fixed schemaVersion=1, immutable observation/device/estate/block UUIDs, kind/unit, decimal value, observedAt and SIMULATED. Topic is the accepted estate/device-specific path; trusted authenticated publisher, topic, registry and payload must agree. No anonymous/wildcard publisher. QoS 1 PUBACK is transport only, not proof of accepted observation; protected result evidence plus persisted query/event establish business acceptance.
- Measurements: AIR_TEMPERATURE/CELSIUS, SOIL_MOISTURE/PERCENT, INTERVAL_RAINFALL/MILLIMETRE. The candidate uses **decimal strings**, up to 12 integer and six fractional digits, absolute maximum 999999999999.999999; no exponent/plus/leading zero/NaN/Infinity encodings. Domain canonicalization makes 27.5 and 27.500000 equivalent. Negative zero is zero. Moisture 0–100 inclusive; rainfall nonnegative with intervalStart < intervalEnd <= observedAt. Other kinds reject interval fields. These are exact wire/representability bounds, not device specifications or agronomic temperature limits.
- Time: canonical lowercase UUIDs; valid UTC Z instants, years 0001–9999, at most millisecond precision, no leap-second encoding. receivedAt is server-owned; observedAt fits explicit generated manifest start/end inclusive and may be at most five minutes ahead of receivedAt. Old in-window arrivals retain history without replacing newer latest. Ties use lowercase UUID lexical order, not receipt order or Java signed UUID comparison. Manifest window and publisher identity never come from payload. Rainfall interval start may precede manifest admission window; the observation time determines admission.
- Event: TelemetryObservationRecorded v1, routing `agrosphere.TelemetryObservationRecorded.v1` on existing agrosphere.domain exchange. Self-contained source=agrosphere-telemetry-service, timestamp=original receivedAt, aggregateId=observationId, aggregateVersion=1, matching estate/block/provenance and immutable payload. One atomic observation/dedup/latest/outbox transaction. Same UUID/equivalent canonical publisher payload is no-op preserving original receipt/event; conflicting reuse rejected/quarantined, never overwritten. Event ID is stable on delivery retry, separate from observation ID. Consumer dedup remains by eventId.
- Parsing/admission: proposed maximum 4096 UTF-8 bytes per MQTT JSON body; reject invalid UTF-8, duplicate JSON keys, unknown properties and noncanonical wire encodings before domain construction. This limit/parsing contract is for later adapters, not enforced by Java BigDecimal alone. Broker queue/in-flight/retry budgets and exact ACL/provisioning/secret delivery must be concretely reviewed before disposable integration. No broker is started now.
